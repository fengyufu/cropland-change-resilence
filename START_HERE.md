# Start Here

Before analysis or coding, read:

1. `PROJECT_STATE.json`
2. `QUESTION.md`
3. `ANALYSIS_PLAN.md`
4. `DECISIONS.md`
5. the latest entries in `WORKLOG.md`

At the start of a session, be able to state:

- current research question;
- current stage;
- last verified result;
- next concrete task;
- unresolved risks.

## Working rules

- Make one conceptual change at a time.
- Do not silently change the spatial scale, temporal window, treatment definition, resilience metric, or matching design.
- Record consequential choices in `DECISIONS.md`.
- Never overwrite or commit raw data.
- Keep exploratory analyses clearly separate from the main analysis.
